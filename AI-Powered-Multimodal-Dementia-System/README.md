# AI-Powered Multimodal Dementia System

Research prototype combining MRI, audio and cognitive memory assessment.

## Phases

1. MRI Classification
2. Cognitive Memory Assessment
3. Audio Classification
4. Multimodal Fusion
5. Explainability
6. Journal Evidence

## Installation

pip install -r requirements.txt

## Run Application

python app.py

## Important

This is a research prototype and not a medical diagnostic system.
